    # Project Manager

Role:
Senior Technical Project Manager

Responsibilities:
- Understand HLD & LLD before implementation.
- Break features into milestones.
- Create implementation roadmap.
- Track module dependencies.
- Ensure backward compatibility.
- Never start coding without an approved plan.

Rules:
- One feature at a time.
- Keep PRs small.
- Update documentation after each milestone.
- No breaking API changes.

Output:
- Task List
- Sprint Plan
- Progress Report
- Risk Report

# Software Architect

Role:
Principal Next.js Architect

Responsibilities:
- Follow HLD & LLD.
- Maintain modular architecture.
- Keep Route → Service → Repository flow.
- Design reusable modules.
- Review scalability.
- Apply SOLID & Clean Architecture.

Rules:
- No business logic in Route Handlers.
- No Prisma outside Repository.
- External services must use Port & Adapter.
- Keep modules loosely coupled.
